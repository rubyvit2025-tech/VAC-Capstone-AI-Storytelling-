# VAC-Capstone-AI-Storytelling-
AI storytelling presentation using sample study data 

1. Project Overview

AI Presentation Storytelling is a project that transforms raw data into meaningful stories and engaging presentations using Artificial Intelligence (AI) tools.

The project uses AI to organize information, identify key insights, generate presentation outlines, create slides, and prepare speaker notes.

2. Problem Definition

Raw data and reports can be difficult to understand. Creating an attractive presentation manually also takes time and effort.

This project uses AI tools to simplify data, identify important information, and convert it into a clear and understandable presentation.

3. Project Objectives

- Convert raw data into a meaningful story.
- Identify key messages and the target audience.
- Generate a structured presentation outline.
- Create presentation slides and speaker notes.
- Visualize important data using charts.
- Verify AI-generated information and correct errors.
- Compare the original and improved presentations.

4. Tools and Technologies

- ChatGPT – Research, prompt engineering, and story outlines.
- Google Sheets – Sample data analysis and charts.
- Canva – Presentation design and visual content.
- Gamma – AI-assisted slide generation.
- Google Slides – Presentation editing and delivery.
- GitHub – Source code, documentation, and project management.
- HTML, CSS, and JavaScript – Optional web-based project interface.

Note: Free-tier availability and features may vary.

5. Project Workflow

1. Select a sample dataset or report.
2. Identify the target audience and main message.
3. Analyze the data and identify key findings.
4. Use AI tools to generate a story outline.
5. Create presentation slides using AI-assisted tools.
6. Add charts, visuals, and speaker notes.
7. Verify facts, figures, and AI-generated content.
8. Correct errors and record the verification results.
9. Compare the initial and final versions.
10. Present and demonstrate the final output.

6. AI Skills Used

- Foundations of Artificial Intelligence
- Prompt Engineering
- AI-Assisted Research
- Content Generation
- Visual Storytelling
- Data Visualization
- Automation and Workflow Design
- Responsible AI and Output Verification

7. Responsible AI

AI-generated information must be checked against reliable sources. Personal or confidential information must not be uploaded to AI tools.

The project will document important prompts, corrections, limitations, and the use of AI tools. All third-party content will be credited appropriately.

8. Expected Outcomes

- A structured story outline.
- A presentation with slides and charts.
- Speaker notes for presenting the topic.
- A prompt library containing useful prompts.
- A verification report documenting errors and corrections.
- A before-and-after comparison.
- A final project demonstration.

9. Final Deliverables

- Story outline
- Presentation slides
- Speaker notes
- Recording or demonstration
- Before-and-after comparison
- Prompt library
- Verification report
- Workflow documentation

10. Conclusion

This project demonstrates how AI tools can transform raw data into clear, informative, and engaging presentations. It combines research, prompt engineering, data visualization, content generation, and responsible AI practices.
